# FlashBattle - Сайт для прокрутки кейсов

Полнофункциональный сайт для прокрутки кейсов с интеграцией скинов CS2, Case Battle, Upgrader и мини-игр!

## 🎮 Функции

### Основные режимы:
1. **Case Battle** - Прокрутка кейсов с выпадением скинов CS2
2. **Upgrader** - Апгрейд скинов с множителями
3. **Crash** - Угадай, когда граф упадёт
4. **Лесенка** - Выбирай правильный путь и поднимайся выше
5. **Сапер** - Найди безопасные клетки и выигрывай

### Особенности:
- 🎨 Современный синий дизайн с градиентами
- 📊 История прокруток слева на панели
- 🔫 10+ скинов CS2 с качеством оружия (FN, MW, FT, WW, BS)
- 💰 Гибкая система ставок
- 🎯 Плавные анимации и переходы
- 💾 Сохранение истории в локальном хранилище

## 🚀 Установка и запуск

### Способ 1: Локально на компьютере
1. Клонируй репозиторий:
```bash
git clone https://github.com/Stylovskiy/FlashBattle.git
cd FlashBattle
```

2. Открой `index.html` в браузере

### Способ 2: Visual Studio Code
1. Откройте папку проекта в VS Code
2. Установите расширение **Live Server**
3. Кликните правой кнопкой на `index.html` и выберите **Open with Live Server**

### Способ 3: GitHub Pages
Сайт автоматически развернётся на GitHub Pages по адресу:
```
https://Stylovskiy.github.io/FlashBattle/
```

## 🎯 Как использовать

### Case Battle:
1. Выбери кейс из выпадающего списка
2. Установи сумму ставки
3. Нажми кнопку "ПРОКРУТИТЬ"
4. Получи случайный скин CS2 с качеством

### Upgrader:
1. Установи сумму для апгрейда
2. Нажми "АПГРЕЙДИТЬ"
3. Получи множитель (x0.5 - x5.0)
4. Видишь результат апгрейда

### Crash:
1. Установи ставку
2. Нажми "НАЧАТЬ"
3. Граф начнёт расти
4. Нажми "ВЫЙТИ" прежде чем граф упадёт
5. Получи выигрыш по множителю

### Лесенка:
1. Установи ставку
2. Выбирай между ЛЕВЫМ и ПРАВЫМ
3. Правильный выбор - поднимаешься выше
4. Неправильный - проигрываешь
5. 5 правильных выборов = полный выигрыш

### Сапер:
1. Установи ставку
2. Нажми "НАЧАТЬ ИГРУ"
3. Кликай на клетки (ищи безопасные)
4. Нажми "ВЫЙТИ И ЗАБРАТЬ" когда захочешь забрать выигрыш
5. Если наступишь на бомбу - проиграешь

## 📱 История прокруток

Слева на экране находится **История прокруток** которая:
- Показывает все твои последние игры
- Отображает тип игры, ставку и результат
- Сохраняется автоматически в браузере
- Максимум последних 50 игр
